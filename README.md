# Планирование маршрутов БПЛА

Данный проект представляет собой интерактивную 3D-симуляцию планирования маршрутов беспилотных летательных аппаратов (БПЛА) в условиях сложного рельефа и наличия статических угроз. Проект разработан на языке Java с использованием библиотеки Swing и собственного движка 3D-визуализации.

В основе алгоритма планирования лежит гибридный подход: **A\*** (A-star) для построения первичного маршрута и **PSO** (Particle Swarm Optimization) для сглаживания траектории и минимизации рисков.

## Основные возможности

*   **Генерация 3D-ландшафта:** Создание случайного горного рельефа с использованием тригонометрических функций.
*   **Моделирование угроз:**
    *   *Горы (конусы):* Физическое препятствие, риск столкновения при полете ниже вершины.
    *   *Радары (сферы):* Зоны обнаружения, риск обратно пропорционален 4-й степени расстояния до источника.
*   **Гибридный алгоритм:**
    *   **A\*** находит базовый путь по сетке, учитывая рельеф и штрафы за подъем.
    *   **PSO** оптимизирует маршрут, делая его плавным и минимизируя интегральный риск от угроз.
*   **Интерактивность:**
    *   Управление 3D-камерой.
    *   Визуализация процесса обучения PSO в реальном времени (отображение частиц, графика сходимости, лучшего маршрута).
    *   Настройка количества дронов (до 8) и типов угроз.

## Технологический стек
*   **Язык:** Java
*   **GUI:** Java Swing
*   **Алгоритмы:** A*, Particle Swarm Optimization (PSO)
